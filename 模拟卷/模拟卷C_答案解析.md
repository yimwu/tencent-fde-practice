### 1 · 单选

踩坑库中一条卡片只写“客户接入后问答变差”，后来同事遇到相同现象仍需从零排查。最应补齐哪组内容？

- A. 更多类似错误现象，但不保留修复步骤
- B. 将卡片改成长篇日记，按每天工作时间排序
- C. 根因、修正动作、适用场景标签与关联 Skill
- D. 发生时间、客户名称与当时使用的版本信息

**答案：C**

踩坑库要记录出错、根因、修正及关联 Skill 的链条，而非错误清单。补齐场景标签便于检索，补齐根因和修正便于执行，再关联通用方法，才能把一次排查变为后续可复用经验。

- **A**：堆现象缺少可执行修正，仍不能降低重复排查成本。
- **B**：按时间扩写不保证根因与修正清晰，检索仍可能困难。
- **C**：完整因果与解法能让同事检索并调用对应方法。
- **D**：时间与版本便于定位背景，但缺少根因和修正仍难复用。

- A. 只核对新场景是否超过原定开发预算
- B. 只统计新场景的准确率，旧场景沿用上次验收数据
- C. 回归测试旧客服场景，确认共享改动未损害原指标

- **B**：共享配置发生变化，上次数据不能证明旧场景仍稳定。
- **C**：Expand要求老场景不受影响，共享改动尤其需要复测。

- **C**：缺少工具输入输出会破坏因果链，不利于合规排查。
- **D**：缩短保留期仍会暴露明文，不能替代敏感字段脱敏或加密隔离。

### 13 · 单选

连接器配置的是一个只能读取销售一区资料的第三方账号。业务方问 AI 能否借此读取销售二区资料。按课程，最准确的说明是什么？

- A. 访问面以专家被下发的部门集合为界，下发到二区即取得二区系统权限
- B. 访问面以连接器配置的第三方账号授权为界，跨区需要另行取得权限
- C. 访问面随当前对话发起人的企业部门变化，连接器配置账号只负责登录
- D. 访问面以本地知识库的可见范围为界，资料可见即允许读取对应实时系统

**答案：B**

连接器以配置时的第三方账号身份执行。企业内部谁能调用专家，与该账号能从外部系统读取什么，是两个不同层次的授权，不能互相替代。

- **A**：专家下发策略控制谁能使用能力，不会自动授予外部系统数据权限。
- **B**：配置账号的既有授权限制实际取数范围，模型不能自行扩大。

- **C**：分别回应边界和安全感，承认人的校验职责。
- **D**：有效使用比数量更有价值，可减少低质刷积分。

- B. 由现场 FDE 判断真实需求与业务约束

财务审核资产准备进库。以下哪些做法守住了沉淀四条红线？

- A. 连接器只接授权范围内的数据，调试时也不默认全开
- B. 为避免专家分歧，由 Agent 自动确认最终付款结论
- C. Agent 给出初筛建议，涉及支付的终审由人留痕确认
- D. 保留失败样本，只对已验证范围内的效果作承诺

**答案：A、C、D**

四红线约束 FDE 行为，包括数据授权、终审责任、失败透明和承诺依据。前三种做法分别落地这些边界；财务专家存在分歧时更需要复核，不能以效率或避免争议为由让 Agent 直接终审。

- **A**：最小必要授权对应不碰不该碰数据的职业底线。
- **B**：自动终审跨越涉及钱和责任归属必须人做的边界。
- **C**：不替客户终审，涉及钱的最终责任应由人承担。
- **D**：不藏失败且不空头承诺，保证沉淀与验收的可信度。

在合同审查项目中，哪些工作属于 Echo 侧的判断产出？

- A. 识别审查返工源于模板不统一，并重新定义待解决的问题
- B. 按已选方案接通解析接口，并定位缺失字段的映射错误

- D. 明确审查准确率和处理时长的目标，并定义业务验收口径

- **B**：联调和映射排错是在既定路径上执行，主要属于 Delta。
- **C**：结合业务约束比较并选择技术路线，是 Echo 的技术判断。
- **D**：确定什么结果算成功，是 Echo 侧的验收标准定义。
